# Proposal

## User
- 平台运营、财务与系统管理员，需要在同一 PC 后台检索和处理 17 个业务域。
## Problem
- 现有页面未覆盖 PC-080..PC-172 的完整清单，也缺乏统一逐条追踪和 UNCONFIRMED 执行保护。
## Scope
- 93 条配置驱动 registry/台账、17 域导航、资金专用工作台、service-only Mock、审计与追踪交付。
## Non-goals
- 不对接真实后端/第三方，不实现移动端，不确认 24 条 UNCONFIRMED 的合同或接口结论。
## Metrics
- 93 个连续唯一 ID、17 域、24 个禁用项；test/typecheck/build 全部通过；追踪 locators 可解析。
